FinSight

A grounded financial-evidence engine over earnings-call transcripts. A single query flows through a six-node LangGraph pipeline — understand → route → hybrid retrieve → rerank → detect conflicts → generate — that cites every claim, refuses when it can't ground an answer, flags stale evidence, and surfaces numeric contradictions instead of averaging them.

Corpus: 15,023 chunks · 76 tickers · 2019–2023  ·  Store: Qdrant Cloud (dense + BM25)  ·  Models: Haiku 4.5 + Sonnet 4.6  ·  Deployed: Render + FastAPI + Streamlit

2 · Conflict detector — the differentiator Sonnet · gated on intent

You (Tab 2 · Conflict)Did company revenue guidance match actual results?
FinSightAnswers, then — when the evidence genuinely disagrees — surfaces an ⚠️ Evidence conflict: e.g. guided +15% vs delivered +9% on the same metric across two calls.
Expect 0 conflicts live (checked 2026-10-05; 0 of 4 guidance queries fired). Don't wait for the flag. Say it before you click: "The detector is precision-first, and standard retrieval rarely returns both a company's guidance and its later actual, so 'none found' is the usual result. The engine is proven on paired evidence: NVDA guided 15%, delivered 9%, fires; a different-segment control doesn't." That's the unit test test_conflict_score_flags_genuine_divergence. The fix is a conflict-aware retrieval mode (DEC-007 revisit trigger). This query also takes ~30–40s because of the extraction call, so run it while you talk.
Point out: this is a dedicated node with its own Sonnet extraction call, not a line in the generation prompt. It pulls structured numeric claims, then pure-Python pairwise-compares them behind four precision gates (different-chunk, comparable-period, same-subject, different-date) that took a naive 6-false-positives-on-query-one down to 0.
Cost gate: the ~14s extraction fires only on comparison/guidance intent (keywords: guidance, versus, revised, compare). Plain queries skip it entirely (0 ms). Other examples in the dropdown: "How did management revise its full-year outlook over the year?"

5 · Abstention — knows what it doesn't know refuses, doesn't guess

You (Tab 1 · Ask)What did Apple say about iPhone sales in 2015?
FinSight"INSUFFICIENT EVIDENCE" — the corpus starts in 2019, so it abstains rather than inventing a figure. Badge flips to Abstained.
Point out: for a regulated buyer (SEC Rule 10b-5), a confident-but-wrong number is worse than a refusal — so the abstention is the product. The generator refuses when retrieved chunks don't support an answer.
More refusals to try: "What is the current stock price of Tesla today?" (not a transcript), "Should I buy or sell Nvidia stock?" (investment-advice guardrail), "Summarize the company's 2025 annual guidance" (after corpus, ends 2023).
The design thesis (say it aloud): probabilistic where language is fuzzy (Haiku routing, Sonnet synthesis), deterministic where correctness must be auditable (RRF fusion, Python conflict comparison, inline citation parsing). Trust gates — grounding, abstention, conflict surfacing, staleness flags — are treated as first-class product features, not afterthoughts.

◧ Architecture at a Glance

Every component below is verified from source in this repo — the LangGraph nodes, retriever, reranker, conflict detector, generator, and eval suite.

User Query → StateGraph.invoke() (LangGraph · linear 6-node DAG · stateless per request) ├─ Node 1 · Understand → Haiku 4.5 (rewrite + ticker hint + temporal ref) ├─ Node 2 · Route → Haiku 4.5 (3-path classify · cost routing) ├─ Node 3 · Retrieve → Qdrant hybrid (dense voyage + BM25 · native RRF fusion) ├─ Node 4 · Rerank → Cohere rerank-v3.5 (+ temporal boost · ms-marco fallback) ├─ Node 5 · Conflicts → Sonnet 4.6 (GATED on comparison intent · ~14s) └─ Node 6 · Generate → Sonnet 4.6 (inline [N] citations · streaming) → "INSUFFICIENT EVIDENCE" (abstains when ungrounded)

Retrieval

  • retriever.py — one Qdrant call, two Prefetch legs
  • Dense (voyage-finance-2) + BM25 sparse, fused server-side by FusionQuery(RRF)
  • Hydrates full chunk text from payload (deploy) or DuckDB (local)
  • reranker.py — Cohere cross-encoder → local ms-marco → raw order (never fails)

The differentiator

  • conflict_detector.py — dedicated Sonnet extraction call
  • Structured NumericClaims → Python pairwise compare
  • Four precision gates killed 6 false positives → 0
  • Thresholds: rev >3%, EPS >5%, margin >1pp, guidance >2pp

Corpus & stores (two-store split)

  • Qdrant Cloud — 15,023 pts · dense + BM25 + text payload
  • DuckDB — columnar system-of-record: documents, chunks
  • Chunks: 600 tokens / 80 overlap · per-corpus strategy
  • SEC fundamentals + OHLCV ingested but not yet on retrieval paths

Serving & observability

  • FastAPI — /health, /query, /query/stream, /recommend, /feedback
  • Lazy singletons + lifespan warmup (no cold-start on first query)
  • LangSmith per-node tracing; per-node latency in the response
  • Per-query cost + 5-mode failure classification (JSONL)

What is not used — and why

CapabilityStatusRationale
Structured XBRL / OHLCV lookupIngested, not wiredOnly transcripts are on the live retrieval paths. The financial_metrics / risk_and_events router paths route correctly but abstain — made honest rather than faking multi-source.
LangGraph checkpointerNot usedSingle-shot Q&A, stateless per request — no multi-turn memory to persist. A checkpointer earns its place only with conversation memory or human-in-the-loop.
Forced tool-use citationsRejectedBuffers the whole JSON and kills streaming (first token 11s→1.3s). Inline [N] markers parsed post-hoc give structured citations and streaming.
Cross-model judge (GPT-4o)SkippedJudge is Claude everywhere for consistency. A rigorous cross-model bake-off needs a bigger labeled set than 50 queries to mean anything.
Roadmap note (worth saying aloud): the right next step is a Context-Builder node that JOINs DuckDB fundamentals by (ticker, period) — you don't embed a number you can look up exactly. That also unlocks the stronger cross-source conflict detector: transcript claim vs filed number. Scoped as future work, not shoehorned in now.
